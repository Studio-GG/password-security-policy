Introduzione

L’app Password Security è progettata per consentire la gestione sicura delle credenziali di accesso (username, password, siti web, note e informazioni correlate) direttamente sul dispositivo Android dell’utente. La tutela della privacy e la sicurezza dei dati personali sono una priorità assoluta.

Raccolta dei dati

L’app non raccoglie, non trasmette e non condivide alcun dato personale. Tutte le informazioni inserite dall’utente vengono memorizzate esclusivamente sul dispositivo locale.

Archiviazione e sicurezza

  • Tutti i dati sono cifrati localmente tramite algoritmi di crittografia avanzati (AES).
  • L’accesso all’app è protetto da una password principale scelta dall’utente.
  • Nessun dato viene inviato via Internet o salvato su server remoti.
  • Disinstallando l’app, tutti i dati vengono definitivamente eliminati dal dispositivo.

Permessi richiesti

L’app può richiedere permessi di sistema esclusivamente per il corretto funzionamento delle funzionalità locali (ad esempio lettura e scrittura di file cifrati). I permessi non vengono utilizzati per raccogliere, monitorare o trasmettere dati personali.

Servizi di terze parti

  • Non utilizza servizi di terze parti
  • Non include pubblicità
  • Non utilizza strumenti di analisi o tracciamento
  • Non effettua profilazione degli utenti

Condivisione dei dati

Non avviene alcuna condivisione di dati con terzi, servizi online o piattaforme esterne.

Diritti dell’utente

  • Lo sviluppatore non può accedere ai dati in alcun modo
  • L’utente mantiene il pieno controllo delle informazioni
  • I dati possono essere eliminati in qualsiasi momento disinstallando l’app

Introduction

The Password Security app is designed to allow secure management of login credentials (usernames, passwords, websites, notes, and related information) directly on the user's Android device. Protecting user privacy and personal data security is a top priority.

Data Collection

The app does not collect, transmit, or share any personal data. All information entered by the user is stored exclusively on the local device.

Storage and Security

  • All data is encrypted locally using advanced encryption algorithms (AES).
  • Access to the app is protected by a master password chosen by the user.
  • No data is transmitted over the Internet or stored on remote servers.
  • Uninstalling the app permanently deletes all stored data from the device.

Permissions

The app may request system permissions strictly necessary for proper local functionality (for example, reading and writing encrypted files). Permissions are not used to collect, monitor, or transmit personal data.

Third-Party Services

  • Does not use third-party services
  • Does not include advertisements
  • Does not use analytics or tracking tools
  • Does not perform user profiling

Data Sharing

No data is shared with third parties, online services, or external platforms.

User Rights

  • The developer cannot access user data in any way
  • Users maintain full control over their information
  • Data can be deleted at any time by uninstalling the app
